# Exercice Python

Ce dépôt contient un simple exercice Python en français.

## Fichier principal

- `main.py` : script principal qui demande le nom, l'âge et le genre de deux personnes, puis affiche un message de présentation.

## Utilisation

Pour exécuter le script :

```bash
python main.py
```

## Description

1. `demander_nom()` : demande le nom et vérifie qu'il n'est pas vide.
2. `demander_age()` : demande l'âge et vérifie qu'un nombre valide est entré.
3. `demander_le_genre()` : demande le genre et accepte seulement `M` ou `F`.
4. `presentation_profil()` : affiche le message de présentation avec l'âge actuel et l'âge de l'année prochaine.

## Notes

- Le script utilise des fonctions pour réutiliser le même comportement pour plusieurs personnes.
- Les messages sont en français et les entrées sont validées.
